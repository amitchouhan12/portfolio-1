# ASP.NET Core Production Bug Fix Lab

A small, realistic backend case study for freelance work. It demonstrates diagnosing and fixing production-style issues in an existing ASP.NET Core API.

## Stack
C#, ASP.NET Core/.NET 8, REST API, EF Core, SQL Server concepts.

## Run
```bash
dotnet restore src/Portfolio.Api/Portfolio.Api.csproj
dotnet run --project src/Portfolio.Api/Portfolio.Api.csproj
```

The environment used to prepare this artifact did not have the .NET SDK installed, so the project could not be executed here. Run the commands above locally before publishing it to GitHub.
